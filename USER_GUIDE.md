# 🌙 Dark Mode & Modal Feature Guide

## How to Use Dark Mode

### Toggle Dark Mode
1. Look for the **moon icon** (🌙) in the navigation bar (top right area)
2. Click the moon icon to enable dark mode
3. The icon will change to a **sun icon** (☀️) in dark mode
4. Click again to return to light mode

### What Changes in Dark Mode?
- **Background:** Light gray → Dark gray
- **Cards:** White → Dark gray
- **Text:** Black → White/Light gray
- **Inputs:** Light → Dark with light text
- **All pages:** Jobs, Dashboard, Navbar adapt automatically

### Dark Mode Persistence
- Your dark mode preference is **saved automatically**
- When you return to the site, it will remember your choice
- Works across all pages and browser sessions

## How to View Job Details & Apply

### Viewing Job Details (Modal Approach)
1. Go to **Browse Jobs** page (http://localhost:5173/jobs)
2. Find a job you're interested in
3. Click the **"View Details"** button on any job card
4. A modal window will open on the **same page** showing:
   - Complete job description
   - Salary and job type
   - Experience level required
   - Application deadline
   - Number of vacancies
   - Required skills
   - Responsibilities
   - Requirements

### Applying for Jobs
1. Open job details modal (see above)
2. Click **"Apply Now"** button (visible only for job seekers)
3. Fill in the application form:
   - **Cover Letter** (required): Explain why you're a good fit
   - **Resume/CV** (required): Upload PDF, DOC, or DOCX (max 5MB)
4. Click **"Submit Application"**
5. Success message will appear
6. Modal closes automatically after 2 seconds

### Closing the Modal
- Click the **X button** in the top-right corner
- Or wait for auto-close after successful application

## Job Seeker Dashboard Features

### Viewing Your Applications
1. Login as job seeker
2. Go to **Dashboard** page
3. Scroll to **"My Applications"** section
4. You'll see all jobs you've applied to with:
   - Job title and company name
   - Application date
   - Current status (Pending/Accepted/Rejected/Shortlisted)
   - Link to view the job again

### Application Status Badges
- **🟡 Pending:** Application is under review
- **🟢 Accepted:** You got the job! Congratulations! 🎉
- **🔴 Rejected:** Unfortunately not selected this time
- **🔵 Shortlisted:** You're on the shortlist for interviews

### Dashboard Stats Cards
Your dashboard shows 4 key metrics:
1. **Available Jobs:** Total jobs you can apply to
2. **Applications:** Number of applications you've submitted
3. **Pending:** Applications waiting for review
4. **Accepted:** Jobs you've been accepted for

## Quick Tips

### For Best Experience
- ✅ Use dark mode in low-light environments
- ✅ Upload high-quality PDF resumes (under 5MB)
- ✅ Write personalized cover letters for each job
- ✅ Check your dashboard regularly for application updates
- ✅ Apply before the deadline shown in job details

### Troubleshooting
- **Modal won't open?** Refresh the page and try again
- **Can't upload resume?** Check file size (must be under 5MB) and format (PDF/DOC/DOCX only)
- **Dark mode not saving?** Make sure cookies/localStorage is enabled in your browser
- **Application not showing?** Check the "My Applications" section on your dashboard
