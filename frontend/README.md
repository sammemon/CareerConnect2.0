# CareerConnect Frontend

Job Recruitment & Internship Portal - React Frontend

## Setup

1. Install dependencies:
```bash
npm install
```

2. Configure environment variables in `.env`

3. Run the development server:
```bash
npm run dev
```

## Build for Production

```bash
npm run build
```

## Technologies

- React.js
- Tailwind CSS
- React Router
- Axios
- Vite
