# CareerConnect Backend

Job Recruitment & Internship Portal - Backend API

## Setup

1. Install dependencies:
```bash
npm install
```

2. Configure environment variables in `.env`

3. Create MySQL database and import `database.sql`

4. Run the server:
```bash
npm run dev
```

## API Documentation

See main README.md for complete API documentation.

## Technologies

- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt for password hashing
